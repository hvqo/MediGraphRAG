# 医学知识与出题平台改造计划

确认日期：2026-10-23。工作分支：`refactor/medigraphrag`。主分支保持不变。

## 已确认的产品方向

面向医学教育，保留出题特色，新增带原文依据的知识问答。本地 Ollama 与云端
OpenAI-compatible 服务可在设置中切换。以单人本地使用为首版范围。

## 阶段与验收

1. **稳定运行**：统一配置和启动入口；缺少模型、索引、Neo4j 时仍可打开服务；
   就绪状态清晰；通用配置不含机器路径或凭据；环境说明可复现。
2. **知识底座**：导入 PDF、DOCX、TXT、Markdown 和粘贴文本；保留文件、页码或
   段落位置；稳定文档/片段 ID；可查询、删除；原文可回看。已有图谱不冒充原始文献。
3. **检索与依据问答**：中文关键词检索为基础，可选 BGE 向量召回和重排；
   图谱提供原文共现关联，区分共现与医学事实；回答引用可核对的片段和原文。
   无依据、无模型或输出未通过校验时明确返回失败，不伪造结果。
4. **出题与题库**：控制题型、难度和数量；校验选项、答案和引用；独立模型复核；
   失败的题目不进入题库；通过自动校验后仍为人工待审；支持编辑、审核、导出。
   后台任务有持久化进度和失败记录。
5. **界面与交付**：资料、问答、出题、题库、图谱、设置页面；拆分组件；
   操作进度和错误反馈；完成接口回归与前端构建，更新使用说明。

## 实施约定

- 每阶段更新 `docs/PROGRESS.md`，记录实际改动、验证、限制及后续工作。
- 验证后按阶段提交并推送到指定分支；不切换、不提交、不合并主分支。
- 模型权重、密钥、虚拟环境、本地资料库、运行日志和机器检查报告不上传。
- 保留 Neo4j/FAISS/BGE 接入能力；首次使用没有这些依赖时可先导入文本并使用
  关键词检索。语义检索和 Neo4j 连通性独立显示，不能将降级模式称为完整 GraphRAG。
- 所有自动生成内容供医学学习、审题使用；医学正确性仍需专业人员审核。

## 首版交付界限

本轮完成上述五阶段的可运行首版。扫描 PDF OCR、医学图像理解、多人权限、
大型知识库性能优化、正式医学准确率评测和生产部署不计入首版完成条件。
PDF 没有可提取文本时提示需要 OCR。引用校验能验证来源和原文匹配，不能等同于
临床正确性证明。图谱共现边不表示因果、治疗或诊断关系。
