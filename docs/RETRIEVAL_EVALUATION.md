# 检索实测报告与结论

日期：2026-10-27。方法实现：`backend/app/retrieval.py`、`routing.py` 与 `relations.py`。
对应源码SHA256、平台/Python/CPU、设置、数据指纹、完整查询和返回ID均在原始JSON中。

## 结论先行

1. **选 `auto` 为产品默认，不宣布医学算法冠军。** 普通问题避开无必要的图谱扩展，关系问题补入审核路径；高级模式保留。
2. 在自建两跳功能集，关键词会漏掉另一段证据，图谱补回；它不证明图谱医学推理正确。
3. 在弱标注的医学来源前缀查找中，关键词与自动都找回已知来源，固定融合未改善排名但增加耗时。
4. 自动P50并不在每个数据集都更低；路径尝试、未命中回退本身有成本。根据真实问题分布再校准策略。
5. **真实BGE向量、重排开关对照、外部GraphRAG/LightRAG框架、医学答案准确率与完整回答延迟均未完成公平实测。**

## 实验A：自建软件功能集

48份文本、16条人工核对的自建软件连接声明，20个独立问题。包括8个直接查找、8个两跳、4个不可答；
答案文档ID明确，存在32份干扰资料。非临床；使用构造编号，关系问题包含规则路由关键词，不能作独立路由泛化验证。

| 策略 | 证据 Recall@5 | MRR | 检索 P50 | 检索 P95 |
| --- | ---: | ---: | ---: | ---: |
| 关键词 BM25 风格 | 75.0% | 1.0000 | 2.77 ms | 4.44 ms |
| 语义向量 BGE / FAISS | 未运行 | — | — | — |
| 审核图谱（仅关系） | 100.0% | 0.9062 | 4.59 ms | 6.06 ms |
| 固定融合 | 100.0% | 1.0000 | 7.45 ms | 15.42 ms |
| 自动路由（默认） | 100.0% | 1.0000 | 7.88 ms | 14.99 ms |

- 直接查找：四种可运行方法的Recall@5均为1；纯图谱MRR为0.8125，其他为1。
- 两跳：关键词Recall@5为0.5，图谱/固定融合/自动均为1。关键词MRR仍为1，说明只看第一个正例排名会漏掉证据不完整的问题。
- 总体Precision@5：关键词0.20，其他三者0.30。分母固定为5，未返回满5条也不会补满分；它是按构造金标准算的文档精确率，不是答案正确率。
- 4个不可答问题均返回空文本结果。这只是空结果测试，不等同于医学安全拒答测试。
- 每个可运行模式20个独立问题×5轮=100次预热后计时；重复轮数不增加独立质量样本。

原始报告：[functional-v1.json](../benchmarks/results/functional-v1.json)。

## 实验B：历史医学文本弱标注来源查找

原仓库`data/knowledge/knowledge.json`共14683条。从长度40–700字的有效记录中，用固定种子20261027采样500条，
文件内容去重后499份资料。选择采样前80条的前12个字符作为查询，已知该记录是一个正例。
没有构建审核图谱；没有真实BGE索引。没有将原历史知识自动认证为医学事实。

| 策略 | 已知来源命中@5 | MRR | 检索 P50 | 检索 P95 |
| --- | ---: | ---: | ---: | ---: |
| 关键词 BM25 风格 | 100.0% | 0.9812 | 46.41 ms | 66.94 ms |
| 语义向量 BGE / FAISS | 未运行 | — | — | — |
| 审核图谱（仅关系） | 未运行 | — | — | — |
| 固定融合 | 100.0% | 0.9812 | 72.96 ms | 106.21 ms |
| 自动路由（默认） | 100.0% | 0.9812 | 45.43 ms | 67.41 ms |

这是**来源已知的词面定位**，容易且偏向BM25。其他相关资料未穷举标注，Precision设为空值。
这不是临床金标准，也不覆盖同义表达、否定、数字/单位、真实跨章节问题与图文。
100%仅表示80个查询都找回已知来源，不能称为“医学召回率/准确率100%”。

原始报告：[legacy-lookup-v1.json](../benchmarks/results/legacy-lookup-v1.json)。

## 指标、环境与复现边界

- Recall@K = 找回的已标注正例数 / 已标注正例数；不可答不并入平均召回。
- Hit@K = 至少一个已标注正例命中的问题比例；MRR = 第一个正例排名倒数的均值。
- Precision@K仅在自建完整标注集上计算，分母固定K；弱标注集不报告Precision。
- P50为中位数，P95为向上取整的95百分位；包含SQLite读取、分词、路由和图谱读取。
- 数据导入/建图/建索引不计时；质量首轮用于预热，后续固定轮数测量；单进程串行调用。
- 不包含HTTP、生成、复核、首字延迟或完整回答时间；当前CPU/Windows小语料测试不代表大规模生产SLA。
- 未安装真实权重或没有审核图谱时不执行对应实验，JSON用`available:false`与原因表示，不能改标成0分。
- 所有实验使用临时数据目录，不污染用户资料、学习记录或模型设置，不调用云端、不以模拟向量替代真实向量成绩。
